# Setu Template Setup

After creating a repository from the GitHub Template:

1. Run `npm install`.
2. Update `src/config/setu.ts` with the project identity and production URL.
3. Replace the starter pages in `src/content/docs/docs/`.
4. Choose `documentation`, `learning`, or `hybrid` as the content mode.
5. Adapt the included playgrounds and quizzes for your content when needed.
6. Run `npm run validate`.
7. Configure the hosting provider and deploy `dist/`.

The GitHub Template and `npm create @rookduel/setu@latest` both include every Setu feature.
