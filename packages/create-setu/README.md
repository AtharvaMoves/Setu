# @rookduel/create-setu

Create a complete RookDuel Setu documentation and learning site:

```bash
npm create @rookduel/setu@latest my-site
```

The generated project includes documentation, learning-page templates, AI-readable output, playgrounds, quizzes, the landing page, and the About page.

Setu was created by **Atharva Sen Barai** and is shared through RookDuel, his personal brand.

Skip dependency installation when integrating the generator into another workflow:

```bash
npm create @rookduel/setu@latest my-site -- --no-install
```

Setu source: [github.com/AtharvaMoves/Setu](https://github.com/AtharvaMoves/Setu)
